# Manualul candidatului – admitere subofițeri, Comunicații (017)

Carte-site pentru pregătirea la testul grilă (3 decembrie 2026): 20 de capitole ordonate după importanță, fișe explicate simplu, desene, flashcard-uri, grile ordonate după probabilitate, simulare de examen și „Refă greșelile”.

**Site:** https://fabian687.github.io/admitere-sof-comunicatii/

## Reconstruire

```
pip install markdown
python3 tools/carte.py
```

Generează `index.html` din `sursa/capitole/`, `sursa/desene/`, `sursa/pagini/`, `sursa/prioritati.txt` și `tools/intrebari/`. Tema și aplicația sunt în `tools/carte_template.html`.
